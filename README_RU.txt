МОИ ДЕЛА — сборка APK через GitHub Actions (с телефона)

1. Создай на GitHub новый репозиторий с названием my-tasks-android.
   Лучше выбрать Public, чтобы не упереться в ограничения GitHub Actions.
2. На странице репозитория нажми Add file → Upload files.
3. Распакуй этот ZIP на телефоне и загрузи ВСЕ файлы и папки из него в корень репозитория.
   Важно: включи скрытую папку .github (в файловом менеджере может понадобиться включить показ скрытых файлов).
4. Нажми Commit changes.
5. Открой вкладку Actions в репозитории.
6. Открой workflow Build Android APK. Если запуск не начался автоматически, нажми Run workflow.
7. Дождись зелёной галочки у запуска.
8. Открой завершённый запуск, прокрути до Artifacts и скачай moi-dela-apk.
9. Распакуй скачанный архив — внутри будет app-debug.apk. Нажми на APK и установи.

Если Android спросит разрешение на установку из этого источника — разреши его для браузера или файлового менеджера.

Данные приложения хранятся локально на телефоне. Удаление приложения или очистка его данных может удалить список дел.
Для обновления приложения потребуется собрать и установить новую версию. Перед удалением старой версии не очищай данные приложения.
